# UML - Classes

One table per layer. Every class of [class-diagram.md](class-diagram.md) appears once. Guide: [guide.md](guide.md). Requirements: RF and RNF from [../requirements/requirements.md](../requirements/requirements.md).

Notes:

- Constructors and getters are not shown.
- Unit tests use `InMemoryUserRepository`, `InMemoryFloorRepository`, `InMemoryLocationRepository`, `InMemoryRoomRepository`, `InMemoryItemRepository` and `InMemoryClientRepository` (in `src/test`). They are test helpers, so they are not in this diagram. `InMemoryLocationRepository.delete` returns false when other rows use the zone.

`StockService.importStock(file, user)` imports every item from a valid XML or JSON file (statement update 2026-11-06). It picks the `StockFileReader` of the `StockFileFormat` of the file name. Both readers give the same `StockFileLine` rows, so the rest of the import has one code path (H4Y-84, Q-59). It creates missing catalogue items and records ENTRY movements. `StockImport` keeps supplier and time; its linked movements identify items and quantities. The PR #20 decision of 2026-10-21 removes the rejected-item field and getter. It does not add a preview API (Q-10, Q-38).
